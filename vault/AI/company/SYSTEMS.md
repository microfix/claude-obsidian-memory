# Systems of record

Which external system owns which kind of data. The archive does **not** copy this data. It holds knowledge, decisions and links. Filled in by the librarian.

| Data | System of record | What the archive holds instead |
|---|---|---|
| Cases, hours, quality-assurance photos, invoicing basis | <!-- e.g. the ERP / project system --> | decisions, customer context, links to the case number |
| Bookkeeping and invoices | <!-- e.g. the accounting system --> | procedures, vendor notes |
| Mail and calendar | <!-- Microsoft 365 --> | meeting notes, decisions |
| Drawings and project files | <!-- e.g. file server / SharePoint --> | where they are and what they are |
